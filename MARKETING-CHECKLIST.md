# Marketing Checklist — Things Only You Can Do

Everything in this file requires a human action: account creation, form submissions,
or decisions that need your personal credentials. Items are ordered by priority
(highest leverage first).

Legend:
- ✅ Built for you — the code/asset exists
- 🔧 Needs your action
- 🚫 Blocked until a dependency is done

---

## 1. Google Search Console (do this first)

**Why first:** GSC tells you what's actually ranking and where your biggest wins are.
Nothing else in this list matters as much.

- 🔧 Go to https://search.google.com/search-console/welcome
- 🔧 Add property: choose "URL prefix" and enter `https://venerable-lollipop-5e026d.netlify.app`
- 🔧 Verify via HTML meta tag (recommended):
  - GSC will give you a `<meta name="google-site-verification" content="XXXXXXX" />` tag
  - Copy just the `content="..."` value
  - In Netlify dashboard: Site settings > Environment variables > Add `PUBLIC_GSC_VERIFICATION=XXXXXXX`
  - Redeploy (push any small change or trigger manual deploy)
  - ✅ The meta tag slot is already wired in `src/layouts/Base.astro`
- 🔧 After verification, submit sitemap:
  - Sitemaps section > Add sitemap URL: `https://venerable-lollipop-5e026d.netlify.app/sitemap-index.xml`
  - ✅ The sitemap is auto-generated by `@astrojs/sitemap` on every build
- 🔧 Also request indexing for your top 5 pages individually (URL Inspection > Request Indexing):
  - `/`
  - `/what-is-a-prediction-market`
  - `/compare`
  - `/guides/how-to-use-kalshi`
  - `/blog`

## 2. Bing Webmaster Tools

**Why:** Bing/Edge powers ChatGPT Browse and Copilot search — underrated for AI-era SEO.
Import from GSC so it takes 5 minutes total.

- 🚫 Blocked until GSC is set up
- 🔧 Go to https://www.bing.com/webmasters/
- 🔧 Sign in with Microsoft account
- 🔧 Click "Import from Google Search Console" — it auto-imports your site and sitemap
- 🔧 For verification: Bing will give you a `<meta name="msvalidate.01" content="XXXXXXX" />` tag
  - Copy the `content` value
  - In Netlify: add env var `PUBLIC_BING_VERIFICATION=XXXXXXX`
  - ✅ The meta tag slot is already wired in `src/layouts/Base.astro`

## 3. Connect GSC to GA4

**Why:** Lets you see which search queries drive sessions, and optimize accordingly.

- 🚫 Blocked until both GSC and GA4 are verified
- 🔧 In GA4 (analytics.google.com), go to Admin > Property Settings > Product Links > Search Console Links
- 🔧 Link your GSC property
- 🔧 In Search Console, go to Settings > Associations > confirm the link

## 4. Weekly Search Console Optimization Loop (ongoing)

**The most valuable 30-minute activity once you have data (start week 3+):**

- 🔧 In GSC: Performance > Search results
- 🔧 Filter: Position 5-20, Impressions > 20, CTR < 5%
- 🔧 For each URL showing in that range:
  - Open the page
  - Is the title tag exactly matching the query that's ranking? If not, update it
  - Does the page answer the query in the first sentence? If not, add a direct answer
  - Add or improve the FAQ section with the exact query phrasing
- 🔧 After each update: URL Inspection > Request re-indexing
- ✅ FAQSchema and ArticleSchema components are already wired — just update the content

**Do this every Monday. It compounds.**

**Week 1-2: observe only**
- 🔧 Create accounts on:
  - https://reddit.com/r/predictionmarkets

  - https://reddit.com/r/Polymarket
  - https://reddit.com/r/sportsbook (sports prediction market angle)
  - https://reddit.com/r/DeFi (crypto prediction market angle)
- 🔧 Read top posts from the last month in each sub — understand what questions repeat
- 🔧 Upvote and save threads with questions your site already answers

**Week 3+: participate genuinely**
- 🔧 Answer 3-5 questions per week where you actually know the answer (no links yet)
- 🔧 After 2-3 weeks of genuine participation, you can occasionally link a guide when it's the
  single best answer to a direct question
- ✅ Reddit comment templates are in `content-assets/social-drafts.md`
