# Short-Form Video Scripts (60-second)

Each script follows the same structure:
- **Hook** (0-5 sec): pattern interrupt — grab attention immediately
- **Body** (5-50 sec): deliver the value, fast
- **CTA** (50-60 sec): one clear next step

---

## Production Notes

- Keep captions on at all times (85%+ viewers watch muted)
- Use screen recordings for platform UI — these outperform talking-head-only formats for "how to" content
- Publish the Kalshi video first (US audience is largest and most searchable)
- Pin the most-viewed script as a comment with the affiliate link
- Respond to every comment for the first 24 hours to boost algorithm signals
